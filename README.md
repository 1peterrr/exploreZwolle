# Explore Zwolle

A web application I built to help Erasmus students discover and share recommendations for places in Zwolle, Netherlands. The idea came from my experience studying there.

## Features

- View recommendations for restaurants, cafés, attractions and nightlife
- Add, edit and delete recommendations
- Include ratings, descriptions and locations
- Add custom categories and optional image URLs
- Include the name of the person recommending a place

## Technologies

Python, Flask, SQLite, Jinja, HTML and CSS.

## Project structure

- app.py — application routes
- database.py — database setup and operations
- templates/ — page templates
- static/ — styles and other static files
